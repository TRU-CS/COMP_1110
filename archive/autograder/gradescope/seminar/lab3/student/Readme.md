## **Assignment Tasks**

### **1. Categorizing Age Groups**
**Description:**  
- Create a program that categorizes a person's age into three groups:  
  - **Minors** (age < 18)
  - **Adults** (18 ≤ age ≤ 64)
  - **Seniors** (age ≥ 65)  
- The program should take age as input from the user and increment the appropriate category counter.

**Requirements:**  
- Use three variables: `minors`, `adults`, and `seniors`.
- Use an **if/else** statement for classification.  

**Points:** 2


### **2. Sum of Squares Using a While Loop**
**Description:**  
- Write a program that computes the sum of squares of the first **50 counting numbers**.  
- The calculation should be:  
  ```
  1*1 + 2*2 + 3*3 + ... + 49*49 + 50*50
  ```
- Store the result in the variable `total`.

**Requirements:**  
- Use **only two variables**: `k` and `total`.  
- Implement the solution using a **while loop**.  

**Points:** 5


### **3. Sum of Cubes of First N Numbers**
**Description:**  
- Compute the sum of cubes for the first **n** natural numbers, where **n** is a positive integer input by the user.  
- The calculation should be:  
  ```
  1³ + 2³ + 3³ + ... + n³
  ```
- Store the result in `total`.

**Requirements:**  
- Use a **while loop**.
- Use **only three variables**: `n`, `k`, and `total`.

**Points:** 5


### **4. Display Even Numbers in a Range**
**Description:**  
- Write a **for loop** to print all even numbers between two user-entered numbers.

**Example:**  
For input range **2 to 10**, the output should be:  
```
2, 4, 6, 8, 10
```

**Requirements:**  
- Use a **for loop** to iterate through the range.
- Print only **even numbers**.

**Points:** 4



### **5. Sum of Digits Using Loops**
**Description:**  
- Write **two programs** to compute the sum of digits of a given number:
  1. Using a **while loop**.
  2. Using a **for loop**.

**Example:**  
For input **1234**, the output should be:  
```
1 + 2 + 3 + 4 = 10
```

**Points:**  
- **While loop version:** 3 points  
- **For loop version:** 3 points
