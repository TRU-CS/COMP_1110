### **4. Generate Patterns**

#### **4.1. Pyramid Pattern**
Write a Python program to generate the following pyramid pattern of the letter "A":

```
      A
     A A
    A A A
   A A A A
  A A A A A
```


#### **4.2. Box Border Pattern**
Write a Python program to generate the following box border pattern using the letter "O":

```
O O O O O
O       O
O       O
O       O
O O O O O
```


#### **4.3. Stair-Step Pattern**
Write a Python program to produce the following stair-step pattern:

```
*  
* *  
* * *  
* * * *  
* * * * *  
```


#### **4.4. Alphabetic Pyramid**
Produce the following pattern using an **alternate method** to what was used for the stair-step pattern:

```
A  
B C  
D E F  
G H I J  
K L M N O  
```
