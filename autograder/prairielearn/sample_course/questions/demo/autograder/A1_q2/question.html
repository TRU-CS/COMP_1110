Exercise 2: Write a Python program to verify if a number is a three-digit number.

Object Name:
You are provided with a file q2.py.

Input:
The program should contain a function called check_three_digit that takes a single integer num as input.

Expected Output:
The program should output whether the number is a three-digit number or not, along with an appropriate message. 

    For example:
    Input: 123
    Output: 123 is a three-digit number.

    Input: 45
    Output: 45 is not a three-digit number.

Edge Cases:
When the user inputs a non-valid input such as a string instead of a number, the program should catch the ValueError exception and print out: 

    Invalid input. Please enter a valid integer.
