Exercise 1: Write a Python program to determine a student's eligibility to sit for an exam based on their attendance.

Object Name:
You have been provided with a file q1.py

Input:
The program should contain a function called check_exam_eligibility that takes two integers as input:

  • total_classes: The number of classes held.
  • classes_attended: The number of classes attended.

Expected Output:
The program should calculate the percentage of classes attended and output:

  1. The percentage of classes attended (formatted to 2 decimal places).
  2. Whether the student is permitted to take the exam (attendance ≥ 90%) or not permitted.
For example: 
    Input: total_classes = 50, classes_attended = 45
    Output:
    Percentage of classes attended: 90.00%
    You are permitted to take the exam.

    Input: total_classes = 50, classes_attended = 40
    Output:
    Percentage of classes attended: 80.00%
    You are not permitted to take the exam.

Edge Cases:
When the user inputs the total number of classes less than or equal to 0, the program should output: 

    The number of total classes must be greater than 0.
